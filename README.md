# Памятка ФСО — восстановленное содержание

`index.html` — текущий интерфейс с 55 исходными основаниями и шестью исходными ситуациями. Основания взяты из `backup/index.original.html`, ситуации — из пользовательской HTML-выгрузки в сохранённой истории. Новые юридические формулировки в эти разделы не добавлялись. Текущая нормативная база и технические исправления сохранены.

`law-sync/` — новая самостоятельная локальная система. Инструкция входа, проверки и Планировщика заданий: `law-sync/README.md`. Она не использует старый архив обновлятора. Сессия форума хранится только локально в `law-sync/.session/`; в поставке этой папки нет.

`backup/before-content-restore/index.html` — версия перед восстановлением. `backup/index.original.html` — исходник до предыдущей переработки. `situations.updated.html` — исходный фрагмент шести ситуаций для серверного хранилища, если оно используется отдельно.

Существующий сервер доступа к памятке и кодов сохранён. Новая проверка законодательства не требует сервера и не выполняется внутри памятки.

Восстановленные формулировки не проходили новый юридический аудит: они возвращены дословно по запросу. Некоторые старые ссылки перечисляют несколько статей, но открывают первую. При изменениях закона такие зависимости проверка отмечает с запасом, чтобы не пропустить связанный материал.
